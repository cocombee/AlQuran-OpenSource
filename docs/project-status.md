# Project status and roadmap

## Current work

AlQuran develops a production workflow for recitation paired with spoken narration of existing Quran translations. The initial production language is Bahasa Indonesia; listening access is intended to be free.

The reusable software in this repository covers narration auditions, local word identification, analysis-window planning, evidence validation, waveform review and a Resolve MCP transport. Current documentation captures the project's production lessons around source provenance, complete-word preservation, connected verses, accepted takes and native playback review.

Production sessions and media are maintained privately. They are not a public dataset or a finished edition catalogue. The repository's existence does not establish completed coverage or an audience count.

## Planned work

| Area | Next step |
| --- | --- |

| Listening access | Build an accessible verse-navigation interface for editions approved for distribution. |
| Language editions | Evaluate a separately sourced and reviewed Bahasa Malaysia edition. |

Each release should state what is implemented, how it was checked and what remains unverified. Features in this roadmap are plans, not shipped capabilities.
